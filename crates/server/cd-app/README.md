# cd-app

Точка входа сервера. Собирает все части вместе и запускает.

## Что делает

1. Читает конфиг и переменные окружения
2. Инициализирует `Engine` через `EngineBuilder`
3. Запускает `cd-net` сервер
4. Держит всё живым

## Не входит в scope

Вся логика — в других крейтах. Здесь только склейка и старт.

## Зависит от

- `cd-engine`
- `cd-net`
- `cd-telemetry`
