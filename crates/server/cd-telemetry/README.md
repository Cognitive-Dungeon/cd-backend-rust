# cd-telemetry

Наблюдаемость движка: события и стримы во внешний мир.  
Движок не знает кто слушает — только эмитит события через трейт.

## Публичный API

- `TelemetrySink` — трейт: реализуй чтобы получать события движка
- `EngineEvent` — перечисление событий (`EntitySpawned`, ...)
- `BroadcastSink` — рассылает событие всем подписчикам
- `NullSink` — заглушка для тестов
