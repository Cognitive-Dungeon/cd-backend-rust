# cd-common

Минимальные типы которые нужны **всем** крейтам — и игровым, и сетевым.

## Публичный API

- `Glyph` — визуальное представление тайла/сущности: цвет (RGB) + ASCII-символ

## Правило этого крейта

Если тип нужен только в одном слое (игра, сеть, данные) — он не попадает сюда.  
Здесь только то без чего нельзя обойтись нигде.
