# cd-core

Фундаментальные типы и математика пространства.  
Не знает про игровую логику, ECS, сеть или данные.

## Публичный API

### Координаты

- `WorldPos` — глобальная 3D позиция в мире (x, y, z)
- `TilePos` — локальная 2D позиция внутри чанка/региона; используется для LOS, pathfinding, AoE
- `ObjectGuid` — уникальный идентификатор объекта (персистентный, используется в БД и сети)

### Математика (`grid/`)

- `Direction` — 10 направлений (4 ортогональных + 4 диагональных + Up/Down)
- `Rect` — прямоугольник из двух `TilePos`
- `neighbors` — константы `NEIGHBORS_4/8` и хелперы `for_each_neighbor_*`
- `shapes` — итераторы по области: `for_each_in_radius`, `for_each_in_square`, `for_each_in_diamond`
- `line` — алгоритм Брезенхэма: `line()`, `line_exclusive()`, `ray()`

## Не входит в scope

- Игровая логика (HP, урон, коллизии)
- ECS-компоненты
- Сетевые типы

## Зависит от

- `cd-common`
