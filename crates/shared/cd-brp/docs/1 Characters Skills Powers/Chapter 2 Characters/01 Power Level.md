## Персонажи (Characters)
Базовое описание концепции персонажа в рамках игровой системы.

### Концепция
Персонаж — это аватар в игровом мире, абстракция его физических и ментальных возможностей, навыков и других дескрипторов. Правила применяют термин `Character` к двум типам сущностей:
1. **Player Characters / PCs (Игровые Персонажи)**: Контролируются игроками. Являются фокусом игры и обладают максимальным уровнем детализации характеристик.
2. **Non-player Characters / NPCs (Неигровые Персонажи)**: Контролируются `Gamemaster` (Гейммастером). Это все остальные существа и люди в мире. 

С точки зрения механики игры, и `PC`, и `NPC` используют абсолютно одни и те же правила и структуры данных. Разница заключается лишь в том, что `NPC` обычно менее детализированы, так как реже сталкиваются с тем же разнообразием ситуаций, что и игроки. Правила создания специфических неигровых существ и монстров описаны в [[Chapter 11: Creatures]]. 

### Архитектура Rust
С точки зрения архитектуры, любой персонаж — это единая структура данных. Тип управления (Игрок или ГМ) можно реализовать через перечисление.

```rust
pub enum CharacterControl {
    Player,     // PC
    Gamemaster, // NPC
}

pub struct Character {
    pub name: String,
    pub control: CharacterControl,
    // Характеристики, навыки и силы будут добавляться 
    // в процессе генерации (Character Creation).
}
```

## Уровень Силы (Power Level)
Глобальный конфигурационный параметр игры, определяющий масштаб возможностей и компетентности персонажей.

### Концепция
`Power Level` (Уровень Силы) задает "рамки реальности" для текущей игровой сессии — от приземленного реализма до мифического эпоса. Этот параметр должен быть выбран до начала создания персонажей, так как он устанавливает лимиты и бюджеты для дальнейших шагов генерации.

Система выделяет 4 базовых уровня силы:
1. **Normal (Нормальный)**: Персонажи не имеют сверхъестественных сил, либо имеют очень мало ненадежных способностей (не более чем выдающийся талант). Подходит для хорроров или современных приключений, где выживание зависит от технологий и смекалки.
2. **Heroic (Героический)**: Персонажи имеют несколько сильных способностей или широкий набор способностей низкого/среднего уровня. Подходит для фэнтези (маги и воины), постапокалипсиса с мутантами, неопытных супергероев или футуристичных сеттингов с генной инженерией.
3. **Epic (Эпический)**: Персонажи невероятно компетентны или обладают могущественными силами. Примеры: архимаги, ветераны-супергерои, могущественные сверхъестественные существа.
4. **Superhuman (Сверхчеловеческий)**: Персонажи с безграничными возможностями, величайшие герои. Примеры: космические стражи, современные полубоги.

### Архитектура Rust
`Power Level` целесообразно реализовать как конфигурационный `enum`, который будет передаваться в фабрику или билдер персонажей (`CharacterBuilder`) для расчета лимитов характеристик, пула очков навыков и доступности особых сил (магии, мутаций и т.д.).

```rust
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum PowerLevel {
    Normal,
    Heroic,
    Epic,
    Superhuman,
}

// Пример использования в глобальной конфигурации или при создании персонажа
pub struct GameSessionConfig {
    pub power_level: PowerLevel,
    // Другие настройки, например включенные Optional Rules
}

impl GameSessionConfig {
    pub fn new(power_level: PowerLevel) -> Self {
        Self {
            power_level,
        }
    }
}
```
