## Базовая механика бросков характеристик (Characteristic Rolls)
Механика, используемая для разрешения ситуаций, которые интуитивно не подпадают ни под один конкретный навык (`Skill`). 

### Механика / Концепция
Если для решения задачи нет подходящего навыка, `Gamemaster` (Гейммастер) может запросить проверку характеристики. Для этого кидается `D100` против значения соответствующей характеристики, умноженной на модификатор сложности.

- **Стандартный модификатор**: По умолчанию характеристика умножается на `5` (например, `STR × 5`).
- **Повышенная сложность**: Для чрезвычайно сложных задач Гейммастер может назначить множитель `×2` или даже `×1` (бросок против "голого" значения характеристики в процентах).

### Архитектура Rust
```rust
pub enum RollMultiplier {
    Standard, // x5
    Hard,     // x2
    Extreme,  // x1
    Custom(u8),
}

impl RollMultiplier {
    pub fn value(&self) -> u8 {
        match self {
            RollMultiplier::Standard => 5,
            RollMultiplier::Hard => 2,
            RollMultiplier::Extreme => 1,
            RollMultiplier::Custom(v) => *v,
        }
    }
}

pub fn calculate_characteristic_target(stat: u8, multiplier: RollMultiplier) -> u16 {
    stat as u16 * multiplier.value() as u16
}
```

## Effort Roll (STR×5)
Бросок усилия, измеряющий грубую физическую силу.

### Механика / Концепция
Большинство проверок силы требуют сопоставления `STR` персонажа с `SIZ` поднимаемого объекта по таблице сопротивления (`Resistance Table`). Однако, если показатель `SIZ` объекта недоступен или его сложно определить, используется `Effort Roll` (бросок усилия). 

Также применяется для быстрых проверок выносливости под нагрузкой (например, вымотался ли персонаж после долгого похода) или гимнастических рывков (подтянуться на уступ).

### Архитектура Rust
```rust
pub fn effort_roll_target(str_val: u8, multiplier: RollMultiplier) -> u16 {
    calculate_characteristic_target(str_val, multiplier)
}
```

## Stamina Roll (CON×5)
Бросок выносливости.

### Механика / Концепция
Базируется на `CON`. Измеряет физическую стойкость и устойчивость организма. Требуется в ситуациях, когда под вопросом физическая или желудочная крепость персонажа. Примеры:
- Не спать всю ночь.
- Перенести морскую болезнь.
- Употребить плохо приготовленную пищу или крепкий алкоголь без последствий для здоровья.

### Архитектура Rust
```rust
pub fn stamina_roll_target(con_val: u8, multiplier: RollMultiplier) -> u16 {
    calculate_characteristic_target(con_val, multiplier)
}
```

## Idea Roll (INT×5)
Бросок идеи или смекалки. Измеряет способность делать умные догадки и дедуктивные выводы на основе наблюдений и "голого" интеллекта.

### Механика / Концепция
Применяется в случаях, когда:
1. **Память и пазлы**: Нужно вспомнить важную деталь, запомнить длинную формулу, найти обратный путь в лабиринте или понять концепцию.
2. **Подсказки Гейммастера**: Если игроки зашли в тупик, успешный `Idea Roll` позволяет Гейммастеру дать им подсказку: раскрыть скрытый смысл найденной улики или сообщить, что "что-то не так" с конкретным человеком или местом. (Этот бросок инициируется Гейммастером, игроки обычно его не просят).
3. **Разделение знаний (Метагейминг)**: Используется для подавления знаний игрока, которыми не обладает персонаж. 
> For example, if a character is a primitive hunter encountering modern technology... your gamemaster may require an Idea roll for them to be able to grasp basic concepts of the item, even if the player automatically knows what it is...

### Архитектура Rust
```rust
pub fn idea_roll_target(int_val: u8, multiplier: RollMultiplier) -> u16 {
    calculate_characteristic_target(int_val, multiplier)
}
```

## Luck Roll (POW×5)
Бросок удачи. Способность оказаться в нужном месте в нужное время или избежать случайной угрозы невредимым.

### Механика / Концепция
Основан на `POW` (Воле/Энергии). Используется как бросок "на везение", чтобы ответить на вопросы:
- Оказался ли у персонажа с собой нужный предмет экипировки?
- Поможет ли случайный прохожий на дороге?
- На кого из группы нападет монстр?
- Упадет ли персонаж в проломившийся пол или успеет зацепиться одеждой за доску?
Успех создает удачное совпадение обстоятельств или спасает от верной гибели в экстренной ситуации.

### Архитектура Rust
```rust
pub fn luck_roll_target(pow_val: u8, multiplier: RollMultiplier) -> u16 {
    calculate_characteristic_target(pow_val, multiplier)
}
```

## Agility Roll (DEX×5)
Бросок ловкости, баланса и координации.

### Механика / Концепция
Применяется для проверок моторных функций, когда не существует подходящего профильного навыка (например, Акробатики). Примеры: удержать баланс на качающейся палубе корабля, быстро собрать осколки разбитой вазы в спешке, бежать с фиалом эликсира и не пролить его, успеть ухватиться за лиану на краю обрыва до падения.

### Архитектура Rust
```rust
pub fn agility_roll_target(dex_val: u8, multiplier: RollMultiplier) -> u16 {
    calculate_characteristic_target(dex_val, multiplier)
}
```

## Charm Roll (CHA×5)
Бросок обаяния и привлекательности.

### Механика / Концепция
Используется для разрешения межличностных реакций, которые не покрываются существующими социальными навыками (такими как `Persuade` или `Fast Talk`). Примеры:
- Произвести хорошее первое впечатление.
- Соблазнить знакомого.
- Стать человеком, к которому группа в первую очередь обращается за советом.
- Привлечь внимание охранника у модного ночного клуба, чтобы тот пропустил персонажа внутрь.

### Архитектура Rust
```rust
pub fn charm_roll_target(cha_val: u8, multiplier: RollMultiplier) -> u16 {
    calculate_characteristic_target(cha_val, multiplier)
}
```

## Опциональное правило: Характеристика Образования (Education / EDU)
Восьмая опциональная характеристика, используемая для генерации очков навыков в современных или футуристических сеттингах.

### Механика / Концепция
`EDU` измеряет уровень общих знаний персонажа, полученных через формальную систему образования или широкий жизненный опыт. 
- **Не заменяет навыки**: Это не замена специфическим знаниям (навыкам), а общая эрудиция.
- **Обучение**: 1 год интенсивного обучения (или школы) не всегда равен 1 очку `EDU`. Но 1 год тяжелой учебы или интенсивных тренировок может повысить `EDU` на `+1`.
- **Потеря памяти**: Амнезия или потеря памяти снижают `EDU`. Значение `EDU 0` указывает на полный вакуум знаний об окружающем мире.
- **Животные**: Животные и существа, опирающиеся на инстинкты, не имеют характеристики `EDU`.

### Граничные случаи и Критические исходы
Падение `EDU` до `0` не делает персонажа недееспособным, но означает полное отсутствие академических/эрудированных знаний об окружающем мире. У животных `EDU` равно `None` (отсутствует).

### Архитектура Rust
```rust
pub struct Education {
    pub value: u8,
}

impl Education {
    pub fn train_one_year(&mut self) {
        self.value = self.value.saturating_add(1);
    }

    pub fn apply_memory_loss(&mut self, amount: u8) {
        self.value = self.value.saturating_sub(amount);
    }
}
```

## Опциональное правило: Бросок Знаний (The Knowledge Roll)
Бросок общей эрудиции и тривии. Базируется на характеристике `EDU`.

### Механика / Концепция
Шанс рассчитывается как `EDU × 5`. Используется для проверки "общих знаний" (general knowledge), которыми обладает среднестатистический человек в конкретном сеттинге или культуре. 
- Крестьянин в Средневековье использует `Knowledge Roll`, чтобы вспомнить имя местного лорда или детали из жития святых.
- Современный гражданин США вспомнит имена важных президентов или что будет, если смешать хлорку и аммиак.
Не заменяет специализированные навыки `Knowledge` (которые опираются на факты и `INT`), а покрывает только общую тривию.

### Архитектура Rust
```rust
pub fn knowledge_roll_target(edu_val: u8, multiplier: RollMultiplier) -> u16 {
    calculate_characteristic_target(edu_val, multiplier)
}
```
