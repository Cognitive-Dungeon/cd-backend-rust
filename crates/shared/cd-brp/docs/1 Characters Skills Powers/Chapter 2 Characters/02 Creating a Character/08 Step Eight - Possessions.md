## Стартовое Имущество (Possessions)
Определение базового снаряжения, экипировки и оружия, которыми персонаж владеет на момент начала игры.

### Механика / Концепция
Детальный учет каждой мелочи не требуется. В лист персонажа записываются только те предметы, которые имеют значение для игры. По умолчанию, если `Gamemaster` (Гейммастер) не установил иные ограничения, каждый персонаж начинает игру со следующим набором:

1. **Одежда**: Полный комплект (или несколько) одежды, подходящей для текущего сеттинга и окружающей среды.
2. **Деньги**: Карманные деньги и личные сбережения, размер которых зависит от уровня богатства (`Wealth level`).
3. **Памятная вещь**: Личный предмет, связывающий персонажа с его прошлым или семьей (фамильная ценность, сувенир или безделушка с сильной эмоциональной связью).
4. **Профессиональные инструменты**: Любые инструменты или оборудование, необходимые для выполнения работы по выбранной профессии (`Profession`).
5. **Оружие**: Любое профильное оружие, если рейтинг навыка владения им (`Skill Rating`) составляет `50%` или выше.
6. **Транспорт**: В зависимости от сеттинга, профессии, уровня богатства и навыка `Status`, персонаж может владеть средством передвижения (лошадь, телега, велосипед, автомобиль, личный флаер, небольшой космический корабль). Требует одобрения Гейммастера.

### Архитектура Rust
Генерация стартового инвентаря может быть автоматизирована на основе ранее выбранных навыков и профессии.

```rust
pub struct CharacterInventory {
    pub clothing: Vec<String>,
    pub savings: WealthLevel,
    pub personal_item: String,
    pub trade_tools: Vec<String>,
    pub weapons: Vec<String>,
    pub vehicles: Vec<String>,
}

impl CharacterInventory {
    // Функция автоматической выдачи оружия на основе навыков (>= 50%)
    pub fn grant_starting_weapons(skills: &[Skill]) -> Vec<String> {
        skills.iter()
            .filter(|skill| skill.is_combat_skill() && skill.current_total() >= 50)
            .map(|skill| format!("Starting weapon for: {}", skill.name))
            .collect()
    }

    // Генерация базового инвентаря
    pub fn new(profession: &Profession, wealth: WealthLevel, skills: &[Skill]) -> Self {
        Self {
            clothing: vec!["Standard setting-appropriate clothing".to_string()],
            savings: wealth,
            personal_item: "Random keepsake".to_string(), // Задается игроком
            trade_tools: profession.get_default_tools(),
            weapons: Self::grant_starting_weapons(skills),
            vehicles: vec![], // Требует ручного согласования с GM
        }
    }
}
```

## Богатство и Статус (Wealth & Status)
Экономическая модель системы Basic Roleplaying по умолчанию абстрактна и опирается на нарративные уровни, а не на точный подсчет монет.

### Механика / Концепция
Детальные правила по финансам в базовой генерации не предоставляются. Начальный уровень богатства диктуется выбранной в [[Step Seven - Profession and Skills|Шаге 7]] профессией. 

Для оценки покупательной способности и возможности раздобыть дополнительное стартовое оборудование (например, редкие предметы, транспорт или недвижимость) используется навык `Status`. Гейммастер использует уровень богатства и броски `Status` как руководство для определения того, к чему персонаж имеет доступ на старте.

### Архитектура Rust
Уровень богатства целесообразно вынести в отдельное перечисление (`enum`), которое будет связано с профессией персонажа и его социальным статусом.

```rust
#[derive(Debug, Clone, Copy, PartialEq, Eq, PartialOrd, Ord)]
pub enum WealthLevel {
    Destitute,
    Poor,
    Average,
    Affluent,
    Wealthy,
}

pub struct FinancialStatus {
    pub wealth_level: WealthLevel,
    // Ссылка на рейтинг навыка Status для проверок влияния/доступа
    pub status_skill_rating: u16, 
}
```
