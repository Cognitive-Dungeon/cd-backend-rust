## Концепция Сил (Powers)
Шаг 2 создания персонажа применяется только в том случае, если игровая сессия подразумевает наличие сверхъестественных или экстраординарных способностей. Если в кампании нет сил, этот шаг полностью пропускается.

### Механика / Концепция
В системе существует пять базовых типов сил (Power Sets). Детальная механика работы каждой из них раскрывается в [[Chapter 4: Powers]], на данном этапе игрок лишь определяет тип источника:
- `Magic` (Магия): Простое использование заклинаний с широким спектром применений.
- `Mutations` (Мутации): Генетические аномалии (как полезные, так и вредные).
- `Psychic Abilities` (Псионика): Использование силы разума для изменения реальности.
- `Sorcery` (Колдовство): Более сложный тип заклинаний, включающий призыв элементалей и демонов.
- `Superpowers` (Суперспособности): Могущественные способности, выходящие за рамки воображения.

Гейммастер может разрешить смешивать в одной партии персонажей с силами и без них (Powered vs. Non-Powered Characters). В качестве балансировки не-магическим персонажам могут быть выданы:
- Компенсация в виде очков навыков (снижение уровня `Power Level` дает повышение бюджета навыков).
- Экипировка (`Equipment`), технологически симулирующая суперспособности.
- "Внутренние" силы (Intrinsic Powers) — обоснование суперспособности как результата экстремальных тренировок или ментальной дисциплины, а не магии.

### Архитектура Rust
```rust
pub enum PowerType {
    Magic,
    Mutation,
    Psychic,
    Sorcery,
    Superpower,
}

// Абстрактный трейт для реализации паттерна "Стратегия" или полиморфизма 
// для различных наборов правил способностей.
pub trait PowerSet {
    fn power_type(&self) -> PowerType;
    fn evaluate_cost(&self) -> i32; // Метод валидации стоимости способностей
}

pub struct CharacterPowers {
    pub active_sets: Vec<Box<dyn PowerSet>>,
    // Все способности всегда используют один и тот же пул очков (Power Points),
    // независимо от того, сколько типов сил есть у персонажа.
}
```

## Уровни Силы (Power Levels) и Баланс
Выбор сил опирается на общий масштаб кампании, который определяет бюджет и доступность сверхъестественного.

### Механика / Концепция
Уровень силы для способностей отделен от бюджета навыков (определяемого в [[07 Step Seven - Profession and Skills|Step Seven]]). Это значит, что Гейммастер может создать игру, где у персонажей `Heroic` бюджет навыков, но `Normal` бюджет сил. 

Градация бюджетов сил:
- **Normal**: Нет сил, одна или пара незначительных сил (экстраординарный талант).
- **Heroic**: Несколько сильных способностей или широкий набор слабых/средних.
- **Epic**: Уровень костюмированных супергероев или архимагов. Высокие ставки.
- **Superhuman**: Первородные сущности, демиурги, могущественные герои космоса.

### Архитектура Rust
```rust
// Уровни силы, специфичные для подсистемы Powers
#[derive(Debug, Clone, Copy, PartialEq, Eq, PartialOrd, Ord)]
pub enum PowerLevelTarget {
    None,
    Normal,
    Heroic,
    Epic,
    Superhuman,
}

pub struct CharacterCreationConfig {
    pub skill_power_level: PowerLevelTarget,
    pub ability_power_level: PowerLevelTarget,
}
```

## Множественные наборы сил (Multiple Power Sets)
Правила ограничивают количество различных типов сил (Power Sets), которыми персонаж может владеть на старте.

### Механика / Концепция
Возможность взять более одного набора сил (например, быть мутантом-телепатом: `Mutations` + `Psychic Abilities`) зависит от общего `Power Level` кампании:

- **Normal Power Level**: Доступен только 1 набор сил на уровне `Normal`.
- **Heroic Power Level** (на выбор):
  - 1 набор сил на уровне `Heroic`.
  - 2 набора сил на уровне `Normal`.
- **Epic Power Level** (на выбор):
  - 1 набор сил на уровне `Epic`.
  - 1 набор на уровне `Heroic` + 1 набор на уровне `Normal`.
  - 3 набора сил на уровне `Normal`.
- **Superhuman Power Level** (на выбор):
  - 1 набор сил на уровне `Superhuman`.
  - 1 набор на уровне `Epic` + 1 набор на уровне `Normal`.
  - 1 набор на уровне `Heroic` + 2 набора на уровне `Normal`.
  - 2 набора сил на уровне `Heroic`.
  - 4 набора сил на уровне `Normal`.

### Архитектура Rust
Алгоритм валидации наборов сил на основе "стоимости" каждого уровня. Если присвоить уровням числовые веса (Normal = 1, Heroic = 2, Epic = 3, Superhuman = 4), математика ограничений становится проверяемой через простой бюджет.

```rust
impl PowerLevelTarget {
    // Внутренний "вес" уровня для композиции множественных наборов
    pub fn weight(&self) -> u8 {
        match self {
            PowerLevelTarget::None => 0,
            PowerLevelTarget::Normal => 1,
            PowerLevelTarget::Heroic => 2,
            PowerLevelTarget::Epic => 3,
            PowerLevelTarget::Superhuman => 4,
        }
    }
}

pub struct SelectedPowerSet {
    pub power_type: PowerType,
    pub level: PowerLevelTarget,
}

pub fn validate_multiple_power_sets(
    campaign_level: PowerLevelTarget, 
    selected_sets: &[SelectedPowerSet]
) -> Result<(), &'static str> {
    
    let max_budget = campaign_level.weight();
    let current_cost: u8 = selected_sets.iter().map(|s| s.level.weight()).sum();

    if current_cost > max_budget {
        return Err("Exceeded allowed budget for multiple power sets");
    }

    Ok(())
}
```

### Граничные случаи и Критические исходы
Даже если персонаж берет несколько наборов сил (например, Магию и Мутации), у него **всегда только один пул `Power Points`**. Нельзя иметь отдельные пулы маны и псионической энергии. Трата очков на заклинание уменьшает общий резерв, что может ограничить использование других способностей. Исключением являются внешние "батареи" (хранилища энергии), если они технологически или логически совместимы с применяемым типом силы (решается Гейммастером).
