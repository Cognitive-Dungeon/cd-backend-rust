## Damage Modifier (Модификатор Урона)
Большие и сильные существа наносят больше физического урона в ближнем бою. Этот модификатор выражается в виде дополнительных или отнимаемых кубиков урона.

### Механика / Концепция
Сложите значения характеристик `STR` и `SIZ` персонажа. Полученная сумма сопоставляется с таблицей для получения модификатора. 

Правила применения:
- Применяется в полном объеме для рукопашного боя (Brawling) и оружия ближнего боя (Melee).
- Делится пополам (округление вверх / `ceil`) для метательного оружия и луков (если модификатор положительный). Отрицательный модификатор не делится.
- Не применяется к огнестрельному и энергетическому оружию.
- Атака не может нанести отрицательный урон. Если модифицированный урон падает ниже 0, он считается равным 0 (удар слишком слаб).

**Таблица Damage Modifier:**
- 2–12: `-1D6`
- 13–16: `-1D4`
- 17–24: Нет (0)
- 25–32: `+1D4`
- 33–40: `+1D6`
- 41–56: `+2D6`
- 57–72: `+3D6`
- 73–88: `+4D6`
- 89–104: `+5D6`
- 105–120: `+6D6`
- И так далее (каждые следующие 16 очков добавляют `+1D6`).

### Архитектура Rust
```rust
pub enum DiceModifier {
    Minus(u8, u8), // Количесто, Грани (напр. 1, 6 -> -1d6)
    None,
    Plus(u8, u8),  // Количесто, Грани (напр. 2, 6 -> +2d6)
}

pub fn get_damage_modifier(str_val: u8, siz_val: u8) -> DiceModifier {
    let total = str_val as u16 + siz_val as u16;
    
    match total {
        0..=12 => DiceModifier::Minus(1, 6),
        13..=16 => DiceModifier::Minus(1, 4),
        17..=24 => DiceModifier::None,
        25..=32 => DiceModifier::Plus(1, 4),
        33..=40 => DiceModifier::Plus(1, 6),
        _ => {
            // Математическая прогрессия для 41 и выше:
            // 41-56 = +2D6, 57-72 = +3D6 (интервал 16)
            let base_extra = total - 40;
            let dice_count = 1 + (base_extra as f32 / 16.0).ceil() as u8;
            DiceModifier::Plus(dice_count, 6)
        }
    }
}
```

### Граничные случаи и Критические исходы
Если выпавший отрицательный модификатор (например, выпало 5 на `-1D6`) превышает базовый урон оружия (например, 3), итоговый урон равен `0`.

## Hit Points (Очки Здоровья)
Показатель способности персонажа выдерживать физический урон.

### Механика / Концепция
Базовый максимум `Hit Points` вычисляется как сумма `CON` и `SIZ`, поделенная на 2 с округлением вверх (`ceil`).
- При достижении `2` или `1` `Hit Points` персонаж теряет сознание.
- При достижении `0` `Hit Points` персонаж умирает в конце следующего боевого раунда.
- Значение может уходить в минус (урон продолжает учитываться).
- Естественное лечение восстанавливает `roll(1, d3)` очков в игровую неделю.

### Опциональные правила
1. **Total Hit Points (Полные Очки Здоровья)**: Для высокоуровневых/героических игр. `Hit Points` вычисляются как `CON` + `SIZ` без деления на 2. Делает персонажей значительно более живучими.
2. **Hit Points by Hit Location (По Зонам Попадания)**: Если используется прицельная стрельба/удары по частям тела, то ХП распределяются на зоны (все дроби округляются вверх `ceil`):
   - Leg (Нога), Abdomen (Живот), Head (Голова) = `1/3` от общих `Hit Points`.
   - Chest (Грудь) = `4/10` от общих `Hit Points`.
   - Arm (Рука) = `1/4` от общих `Hit Points`.
   Сумма ХП всех зон превышает общее значение, но любой урон вычитается **одновременно** и из локации, и из общего пула `Hit Points`.

### Архитектура Rust
```rust
pub struct HitPoints {
    pub current: i16,
    pub max: u16,
}

pub fn calculate_max_hp(con: u8, siz: u8, use_total_hp_rule: bool) -> u16 {
    let sum = con as f32 + siz as f32;
    if use_total_hp_rule {
        sum as u16
    } else {
        (sum / 2.0).ceil() as u16
    }
}

pub struct HitLocations {
    pub head_hp: u16,
    pub abdomen_hp: u16,
    pub chest_hp: u16,
    pub right_arm_hp: u16,
    pub left_arm_hp: u16,
    pub right_leg_hp: u16,
    pub left_leg_hp: u16,
}

pub fn calculate_hit_locations(total_hp: u16) -> HitLocations {
    let hp = total_hp as f32;
    let one_third = (hp / 3.0).ceil() as u16;
    let four_tenths = (hp * 0.4).ceil() as u16;
    let one_fourth = (hp / 4.0).ceil() as u16;

    HitLocations {
        head_hp: one_third,
        abdomen_hp: one_third,
        right_leg_hp: one_third,
        left_leg_hp: one_third,
        chest_hp: four_tenths,
        right_arm_hp: one_fourth,
        left_arm_hp: one_fourth,
    }
}
```

## Major Wounds (Тяжелые Ранения)
Система порога урона, при превышении которого персонаж получает серьезные увечья.

### Механика / Концепция
Уровень `Major Wound` (Тяжелого Ранения) равен половине от максимальных `Hit Points` персонажа с округлением вверх (`ceil`). Если за один удар персонаж получает урон, равный или превышающий этот порог, помимо потери ХП он страдает от дебилитирующего эффекта (бросок по специальной таблице, детальная механика раскрывается в [[Chapter 6: Combat]]).

*Примечание:* Это правило конфликтует с опциональным правилом `Hit Points by Hit Location`. Рекомендуется использовать либо одно, либо другое.

### Архитектура Rust
```rust
pub fn calculate_major_wound_threshold(max_hp: u16) -> u16 {
    (max_hp as f32 / 2.0).ceil() as u16
}
```

## Power Points (Очки Силы)
Топливо для использования магических заклинаний, мутаций, псионики и других сверхспособностей.

### Механика / Концепция
Максимальное количество `Power Points` (PP) всегда равно характеристике `POW`. 
- Не могут опускаться ниже `0`.
- Если значение падает до `0`, персонаж полностью истощен и теряет сознание (падает в обморок), пока не восстановит хотя бы `1` PP.
- Очки восстанавливаются со временем в зависимости от максимального пула и состояния персонажа (Сон или Бодрствование). Если персонаж занимается тяжелой физической активностью, PP не восстанавливаются.

**Таблица восстановления Power Points:**
- **Max PP 1–24**: Во сне: 1 в час. Бодрствуя: 1 за 2 часа.
- **Max PP 25–48**: Во сне: 2 в час. Бодрствуя: 1 в час.
- **Max PP 49–72**: Во сне: 3 в час. Бодрствуя: 1 за 40 минут.
- **Max PP 73–96**: Во сне: 4 в час. Бодрствуя: 1 за 30 минут.
- **Max PP 97+**: +1 в час за каждую градацию.

### Архитектура Rust
```rust
pub struct PowerPoints {
    pub current: u16, // Не может быть меньше 0
    pub max: u16,     // Равен POW
}

pub enum ActivityState {
    Sleeping,
    AwakeResting,
    StrenuousActivity,
}

pub fn get_pp_recovery_rate_per_hour(max_pp: u16, state: ActivityState) -> f32 {
    if let ActivityState::StrenuousActivity = state {
        return 0.0;
    }

    match max_pp {
        1..=24 => if let ActivityState::Sleeping = state { 1.0 } else { 0.5 },
        25..=48 => if let ActivityState::Sleeping = state { 2.0 } else { 1.0 },
        49..=72 => if let ActivityState::Sleeping = state { 3.0 } else { 1.5 }, // 1 за 40 мин = 1.5 в час
        73..=96 => if let ActivityState::Sleeping = state { 4.0 } else { 2.0 }, // 1 за 30 мин = 2 в час
        _ => {
            // Формула для 97+ (шаг 24 очка)
            let multiplier = ((max_pp - 1) / 24) as f32;
            if let ActivityState::Sleeping = state { 1.0 + multiplier } else { (1.0 + multiplier) / 2.0 }
        }
    }
}
```

## Experience Bonus (Бонус Опыта)
Модификатор скорости обучения. Чем умнее персонаж, тем быстрее он учится под стрессом.

### Механика / Концепция
`Experience Bonus` равен `INT` поделенному на 2, с округлением вверх (`ceil`). Этот бонус прибавляется к каждому броску проверки опыта (`Experience Check`) при попытке улучшить навык или характеристику (детальная механика улучшения описывается в [[Chapter 5: System]]).

### Архитектура Rust
```rust
pub fn calculate_experience_bonus(int_val: u8) -> u8 {
    (int_val as f32 / 2.0).ceil() as u8
}
```

## Movement (Движение)
Базовая скорость передвижения.

### Механика / Концепция
Для людей и гуманоидов атрибут `Move` (`MOV`) по умолчанию равен `10`. Это означает, что персонаж может переместиться на 10 единиц (метров) за один `Combat Round` при обычном (неспешном) движении.

### Архитектура Rust

pub const BASE_HUMAN_MOV: u8 = 10;

## Опциональное правило: Fatigue Points (Очки Усталости)
Детализированная система выносливости для учета тяжелых нагрузок.

### Механика / Концепция
Максимальные `Fatigue Points` равны сумме `STR` + `CON`.
- Персонаж тратит `1` FP за каждый раунд тяжелой активности (ближний бой, бег, плавание).
- Форсированный марш стоит `1` FP в час.
- В отличие от `Hit Points`, персонаж может действовать, когда `Fatigue Points` падают ниже `0`.
- **Штрафы**: За каждое отрицательное очко усталости персонаж получает штраф `-1%` на все броски навыков, характеристик и сопротивления.
- **Истощение**: Когда отрицательное значение `Fatigue Points` сравнивается с базовым максимумом (например, `-20` при базе `20`), персонаж физически не может продолжать действия (Incapacitated) и может упасть в обморок.
- **Восстановление**: 1 FP восстанавливается каждые 5 раундов (1 минута) отдыха.

### Альтернатива: Simple Fatigue (Простая Усталость)
Без подсчета очков. Персонаж дерется `CON × 3` раундов без проблем. После этого он "Уставший" (все броски становятся `Difficult`). После `CON × 4` раундов навыки падают до `1/4` от номинала. После `CON × 10` наступает крайнее истощение (для любого действия нужен бросок `Stamina`, а навыки ограничены `POW × 1%`).

### Архитектура Rust
```rust
pub struct FatiguePoints {
    pub current: i16,
    pub max: u16, // STR + CON
}

impl FatiguePoints {
    pub fn get_penalty(&self) -> i16 {
        if self.current < 0 {
            self.current // Возвращает отрицательное число, эквивалентное % штрафа
        } else {
            0
        }
    }

    pub fn is_incapacitated(&self) -> bool {
        self.current <= -(self.max as i16)
    }
}
```

## Опциональное правило: Sanity Points (Очки Рассудка)
Используется в играх жанра хоррор.

### Механика / Концепция
Максимальные начальные `Sanity Points` (SAN) равны `POW × 5`. 
В игре персонажи теряют `SAN` при виде ужасающих сцен. Если `SAN` падает до `0`, персонаж становится неиграбельным (сходит с ума окончательно).

### Архитектура Rust
```rust
pub struct SanityPoints {
    pub current: i16,
    pub max: u16, // Обычно 99, но старт = POW * 5
}
```

## Опциональное правило: Skill Bonuses (Бонусы к Категориям Навыков)
Позволяет характеристикам влиять на стартовые шансы соответствующих групп навыков.

### Механика / Концепция
Все навыки делятся на категории (Combat, Communication, Manipulation, Mental, Perception, Physical). У каждой категории есть `Primary` (первичная), `Secondary` (вторичная) и `Negative` (негативная) характеристики.

**Формула расчета бонуса категории:**
- **Primary**: +1% за каждое очко характеристики свыше 10; -1% за каждое очко ниже 10.
- **Secondary**: +1% за каждые полные 2 очка свыше 10; -1% за каждые полные 2 очка ниже 10 (округление вниз / `floor`).
- **Negative**: -1% за каждое очко свыше 10; +1% за каждое очко ниже 10.

*Пример*: `Physical` зависит от `DEX` (Primary), `STR` и `CON` (Secondary), `SIZ` (Negative). Для `DEX 12 (+2)`, `STR 14 (+2)`, `CON 13 (+1)`, `SIZ 12 (-2)` бонус категории Physical составит: `+2 + 2 + 1 - 2 = +3%`. Этот бонус прибавляется ко всем навыкам в категории.

### Альтернатива: Simpler Skill Bonuses (Упрощенные бонусы)
Если сложные формулы не подходят, бонус категории равен просто: `Primary Характеристика / 2` (с округлением вверх `ceil`). Негативных модификаторов в этой версии нет.

### Архитектура Rust
```rust
pub enum SkillCategory {
    Combat,
    Communication,
    Manipulation,
    Mental,
    Perception,
    Physical,
}

// Расчет по полной формуле
pub fn calculate_category_bonus(primary: u8, secondary: &[u8], negative: Option<u8>) -> i16 {
    let mut bonus: i16 = 0;

    // Primary
    bonus += primary as i16 - 10;

    // Secondary
    for &sec in secondary {
        let diff = sec as i16 - 10;
        bonus += diff / 2; // Целочисленное деление в Rust делает trunc (округление к нулю), что удовлетворяет правилу
    }

    // Negative
    if let Some(neg) = negative {
        bonus -= neg as i16 - 10;
    }

    bonus
}

// Расчет по упрощенной формуле
pub fn calculate_simple_category_bonus(primary: u8) -> u16 {
    (primary as f32 / 2.0).ceil() as u16
}
```
