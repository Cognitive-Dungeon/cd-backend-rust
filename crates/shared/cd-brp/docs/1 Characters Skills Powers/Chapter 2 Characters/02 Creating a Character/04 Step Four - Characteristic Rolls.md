## Броски характеристик (Characteristic Rolls)
После финального определения всех значений базовых характеристик (после всех модификаций от возраста, перераспределения очков и применения опциональных правил), необходимо вычислить процентные значения для стандартных проверок.

### Механика / Концепция
Эти броски используются в ситуациях, когда нет подходящего специфического навыка (`Skill`), но необходимо проверить базовые возможности персонажа: силу, выносливость, смекалку или удачу. Каждое значение рассчитывается путем умножения соответствующей характеристики на `5`. 

- **Effort Roll (Бросок Усилия)**: `STR × 5`. Используется для проверки сырой физической силы (подтянуться на уступ, перенести тяжесть в конце долгого похода).
- **Stamina Roll (Бросок Выносливости)**: `CON × 5`. Измеряет физическую крепость (не заснуть всю ночь, сопротивляться морской болезни, переварить плохую еду или выпивку).
- **Idea Roll (Бросок Идеи)**: `INT × 5`. Способность делать догадки, улавливать подсказки, запоминать сложную информацию или замечать скрытый смысл. Гейммастер может использовать этот бросок, чтобы помочь "застрявшим" игрокам или разграничить знания игрока и знания персонажа.
- **Luck Roll (Бросок Удачи)**: `POW × 5`. Определяет случайные совпадения: повезет ли найти нужный предмет, обвалится ли пол под персонажем, нападет ли монстр на него или на NPC.
- **Agility Roll (Бросок Ловкости)**: `DEX × 5`. Проверка баланса, координации и рефлексов (удержаться на скользкой палубе, быстро собрать упавшие предметы, не упасть с обрыва).
- **Charm Roll (Бросок Обаяния)**: `CHA × 5`. Первое впечатление, попытка понравиться, соблазнение или привлечение внимания в толпе (если нет подходящего социального навыка).

**Опциональное правило:**
- **Knowledge Roll (Бросок Знаний)**: `EDU × 5`. Доступен только если используется опциональная характеристика `Education` (Образование). Используется для общих знаний, фактов и тривии ("что будет, если смешать хлорку и аммиак?", "имя исторического деятеля"). Не заменяет специализированные навыки группы `Knowledge`.

### Архитектура Rust
Каждое производное значение можно реализовать как метод структуры характеристик. Возвращаемое значение ограничено типом `u8`, так как используется для процентных бросков (D100). Максимальное значение может превышать 100% (например, при характеристике 21 бросок будет 105%), поэтому использование насыщающего умножения (`saturating_mul`) здесь опционально или должно ограничиваться логикой бросков свыше 100%. В данном случае оставим математику прозрачной.

```rust
// Структура из Шага 1 с добавленными методами для Шага 4
pub struct Characteristics {
    pub str: u8,
    pub con: u8,
    pub siz: u8,
    pub int: u8,
    pub pow: u8,
    pub dex: u8,
    pub cha: u8,
    pub edu: Option<u8>, // Опциональная характеристика
}

impl Characteristics {
    pub fn effort_roll(&self) -> u16 {
        self.str as u16 * 5
    }

    pub fn stamina_roll(&self) -> u16 {
        self.con as u16 * 5
    }

    pub fn idea_roll(&self) -> u16 {
        self.int as u16 * 5
    }

    pub fn luck_roll(&self) -> u16 {
        self.pow as u16 * 5
    }

    pub fn agility_roll(&self) -> u16 {
        self.dex as u16 * 5
    }

    pub fn charm_roll(&self) -> u16 {
        self.cha as u16 * 5
    }

    pub fn knowledge_roll(&self) -> Option<u16> {
        self.edu.map(|edu_val| edu_val as u16 * 5)
    }
}
```

### Граничные случаи и Критические исходы
Поскольку базовая генерация позволяет иметь характеристики до `21` (а при некоторых опциональных правилах и выше), значения `Characteristic Rolls` могут быть больше `100%`. В BRP это допустимая механика — шансы выше 100% увеличивают вероятность критических и особых успехов, а также помогают нивелировать негативные модификаторы сложности. Бросок `99` или `00` (100) на костях всегда остается провалом (`Fumble`), даже если рейтинг превышает 100%.
