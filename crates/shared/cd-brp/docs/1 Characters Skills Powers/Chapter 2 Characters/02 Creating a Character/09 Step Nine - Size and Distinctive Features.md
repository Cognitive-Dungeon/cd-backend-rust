## Размер и Габариты (Size / Height and Weight)
Косметический шаг, описывающий физические параметры персонажа. Не является строго обязательным с точки зрения математики игры.

### Механика / Концепция
Игрок определяет точный рост и вес персонажа (или описывает их абстрактно, например "Высокий" или "Стройный"), основываясь на характеристике `SIZ` (Size). 

**Шкала SIZ для человека:**
- **SIZ 8**: Минимальный размер здорового человека. Относительно маленький, низкого роста или субтильного телосложения.
- **SIZ 10–13**: Среднестатистический человеческий диапазон роста и веса.
- **SIZ 18**: Чрезвычайно крупный, высокий или тучный человек (максимум для базовой генерации).

### Архитектура Rust
```rust
pub struct PhysicalAppearance {
    pub height_description: String,
    pub weight_description: String,
}

// Вспомогательная функция для генерации текстового описания на основе SIZ
pub fn get_default_size_description(siz: u8) -> &'static str {
    match siz {
        1..=7 => "Exceptionally small / Child-sized",
        8..=9 => "Small / Slender",
        10..=13 => "Average human build",
        14..=17 => "Large / Tall",
        18..=21 => "Exceptionally large / Massive",
        _ => "Superhumanly massive",
    }
}
```

## Опциональное правило: Отличительные Черты (Distinctive Features)
Система добавления колорита и уникальных внешних особенностей персонажу. Не несет механических бонусов или штрафов.

### Механика / Концепция
Количество отличительных черт зависит от характеристики `CHA` (Харизма). Чем дальше значение от среднего (как в меньшую, так и в большую сторону), тем больше у персонажа выделяющихся черт.

**Таблица количества черт (Distinctive Features Table):**
- **CHA 3 или меньше**: 4 черты
- **CHA 4–7**: 3 черты
- **CHA 8–9**: 2 черты
- **CHA 10–11**: 1 черта
- **CHA 12–14**: 2 черты
- **CHA 15–16**: 3 черты
- **CHA 17+**: 4 черты

**Как выбирать черты:**
Игрок бросает `roll(1, d10)` (или выбирает вручную) категорию для каждой положенной ему черты. Затем игрок придумывает конкретную особенность или выбирает из предложенных вариантов внутри категории.
1. **Hair on Head (Волосы)**: Лысый, дреды, спутанные, яркий цвет, парик, вши и т.д.
2. **Facial Hair (Растительность на лице)**: Сросшиеся брови, огромные усы, длинная борода и т.д.
3. **Facial Feature (Особенности лица)**: Родинка, гетерохромия, сломанный нос, шрам, клыки, татуировка и т.д.
4. **Expression (Выражение лица)**: Загадочное, хмурое, добродушное, наивное, высокомерное и т.д.
5. **Clothes (Одежда)**: Дорогая, лохмотья, вульгарная, старомодная, униформа и т.д.
6. **Bearing (Осанка / Поведение)**: Неуклюжий, военная выправка, сутулый, дерзкий и т.д.
7. **Speech (Речь)**: Акцент, заикание, гнусавость, глубокий голос, шепот и т.д.
8. **Arms and Hands (Руки)**: Отсутствие пальца, мозоли, кольца, татуировки, слишком длинные руки и т.д.
9. **Torso (Торс)**: Бочкообразный, шрамы, нет пупка, сгорбленный, волосатый и т.д.
10. **Legs and Feet (Ноги)**: Хромота, мозолистые стопы, отсутствие пальца, колесообразные ноги и т.д.

Если `CHA` низкая (9 или ниже), эти черты обычно неприятные, отталкивающие или странные. Если `CHA` высокая (12+), черты привлекательные или впечатляющие (даже если сама черта обычно не считается красивой). Однако это правило не является строгим ограничением.

### Архитектура Rust
```rust
pub fn calculate_distinctive_features_count(cha_stat: u8) -> u8 {
    match cha_stat {
        0..=3 => 4,
        4..=7 => 3,
        8..=9 => 2,
        10..=11 => 1,
        12..=14 => 2,
        15..=16 => 3,
        _ => 4, // 17 и выше
    }
}

pub enum FeatureCategory {
    HairOnHead,
    FacialHair,
    FacialFeature,
    Expression,
    Clothes,
    Bearing,
    Speech,
    ArmsAndHands,
    Torso,
    LegsAndFeet,
}

pub struct DistinctiveFeature {
    pub category: FeatureCategory,
    pub description: String,
}

impl FeatureCategory {
    pub fn roll_random_category() -> Self {
        match roll(1, d10) {
            1 => FeatureCategory::HairOnHead,
            2 => FeatureCategory::FacialHair,
            3 => FeatureCategory::FacialFeature,
            4 => FeatureCategory::Expression,
            5 => FeatureCategory::Clothes,
            6 => FeatureCategory::Bearing,
            7 => FeatureCategory::Speech,
            8 => FeatureCategory::ArmsAndHands,
            9 => FeatureCategory::Torso,
            _ => FeatureCategory::LegsAndFeet, // 10
        }
    }
}
```
