## Базовые правила характеристик (Characteristics)
Характеристики измеряют и определяют физические и ментальные возможности персонажа. Они не статичны и могут меняться в процессе игры: повышаться от тренировок и падать от травм или болезней.

### Механика / Концепция
Характеристики делятся на две категории, имеющие разные системные ограничения для людей (могут отличаться для других видов):
- **Физические характеристики** (`STR`, `CON`, `SIZ`, `DEX`, `CHA`): Имеют жесткий максимум в **21** единицу для обычного человека.
- **Ментальные характеристики** (`INT`, `POW`, опционально `EDU`): Обычно не имеют максимума и могут расти бесконечно в процессе учебы или духовного развития.

**Минимальные значения:**
При снижении от штрафов или болезней минимально возможное значение любой характеристики (кроме `SIZ` и `INT`) равно **3**. Для `SIZ` и `INT` минимальное значение равно **8**. Падение характеристики до **0** вызывает фатальные или критические последствия для персонажа. 

*Примечание:* Магия, мутации и сверхспособности могут увеличивать характеристики сверх любых лимитов.

### Архитектура Rust
```rust
pub const MIN_NORMAL_STAT: u8 = 3;
pub const MIN_SIZ_INT_STAT: u8 = 8;
pub const MAX_HUMAN_PHYSICAL_STAT: u8 = 21;

pub enum StatType {
    Physical,
    Mental,
}

pub fn get_stat_type(stat_name: &str) -> StatType {
    match stat_name {
        "STR" | "CON" | "SIZ" | "DEX" | "CHA" => StatType::Physical,
        "INT" | "POW" | "EDU" => StatType::Mental,
        _ => panic!("Unknown stat"),
    }
}
```

## Strength (STR) - Сила
Измеряет мышечную силу.

### Механика / Концепция
- **Связанный бросок**: `Effort roll` (`STR × 5`).
- **Применение**: Определяет, сколько персонаж может поднять, толкнуть или унести. Ограничивает использование тяжелого оружия. Является компонентом формулы `Damage Modifier` (вместе с `SIZ`).
- **Изменение**: Увеличивается тренировками, уменьшается травмами и болезнями.

### Граничные случаи и Критические исходы
- **При `STR` 0**: Персонаж становится инвалидом, неспособным встать с постели.

### Архитектура Rust
```rust
pub fn check_str_state(str_val: u8) -> Result<(), &'static str> {
    if str_val == 0 {
        return Err("Character is bedridden and invalid.");
    }
    Ok(())
}
```

## Constitution (CON) - Телосложение
Измеряет здоровье, энергичность и живучесть.

### Механика / Концепция
- **Связанный бросок**: `Stamina roll` (`CON × 5`).
- **Применение**: Определяет сопротивляемость усталости, ядам, болезням и утоплению. Является компонентом формулы `Hit Points` (вместе с `SIZ`).
- **Изменение**: Увеличивается физической подготовкой. Временно или навсегда снижается болезнями и ядами.

### Граничные случаи и Критические исходы
- **При `CON` 0**: Персонаж мгновенно умирает.

### Архитектура Rust
```rust
pub fn check_con_state(con_val: u8) -> Result<(), &'static str> {
    if con_val == 0 {
        return Err("Character is dead due to CON 0.");
    }
    Ok(())
}
```

## Size (SIZ) - Размер
Определяет рост, вес и массу тела.

### Механика / Концепция
- **Связанный бросок**: Нет ассоциированного броска, умножаемого на 5. Вместо этого `SIZ` используется в таблице сопротивления (`Resistance Table`) для удержания позиций (standing firm) или протискивания в щели.
- **Применение**: Компонент формул `Hit Points` и `Damage Modifier`. Высокий `SIZ` дает бонусы к массе и выживаемости, но мешает в скрытности (`Stealth`).
- **Изменение**: Может меняться от диет или переедания (по решению ГМ'а), тяжелых травм (потеря конечностей) или суперспособностей.

### Граничные случаи и Критические исходы
- **Потеря 50% SIZ**: Если персонаж теряет более половины своего `SIZ` (округление вверх / `ceil`) из-за голодания или экстремальной диеты, он умирает.
- **При `SIZ` 0**: (Обычно в результате магии) Персонаж просто исчезает, истощаясь в ничто.

### Архитектура Rust
```rust
pub fn check_siz_state(current_siz: u8, max_siz: u8) -> Result<(), &'static str> {
    if current_siz == 0 {
        return Err("Character wastes away to nothing and disappears.");
    }
    if current_siz as f32 <= (max_siz as f32 / 2.0).ceil() {
        // Условие смерти от голода (опционально, если SIZ потерян именно так)
        return Err("Character dies from starvation/extreme diet.");
    }
    Ok(())
}
```

## Intelligence (INT) - Интеллект
Измеряет логику, память, способность учиться и анализировать.

### Механика / Концепция
- **Связанный бросок**: `Idea roll` (`INT × 5`).
- **Применение**: Важнейшая характеристика для определения стартовых очков навыков. Представляет разум. Не имеет фиксированного максимума.
- **Изменение**: Увеличивается обучением и ментальными упражнениями. Снижается от травм головы, наркотиков и болезней.

### Граничные случаи и Критические исходы
- **При `INT` 0**: Персонаж превращается в "овощ", находясь в вегетативном состоянии, неспособный к самостоятельному выживанию.

### Архитектура Rust
```rust
pub fn check_int_state(int_val: u8) -> Result<(), &'static str> {
    if int_val == 0 {
        return Err("Character is in a vegetative state.");
    }
    Ok(())
}
```

## Power (POW) - Энергия / Воля
Неосязаемая характеристика, представляющая силу воли, духовное развитие и магические способности.

### Механика / Концепция
- **Связанный бросок**: `Luck roll` (`POW × 5`).
- **Применение**: Определяет лидерство, интуицию. Полностью диктует стартовые `Power Points` и `Sanity Points`. Как и интеллект, не имеет лимита на развитие.
- **Изменение**: Некоторые магические заклинания требуют перманентного пожертвования очков `POW`.

### Граничные случаи и Критические исходы
- **При `POW` 0**: Персонаж теряет душу и становится кататоником, лишенным воли и жизненной силы.

### Архитектура Rust
```rust
pub fn check_pow_state(pow_val: u8) -> Result<(), &'static str> {
    if pow_val == 0 {
        return Err("Character has lost their soul and is catatonic.");
    }
    Ok(())
}
```

## Dexterity (DEX) - Ловкость
Мера баланса, проворства, скорости и координации.

### Механика / Концепция
- **Связанный бросок**: `Agility roll` (`DEX × 5`).
- **Применение**: Критична для реакции на атаки, скрытного перемещения и тонкой работы. База для `DEX Rank` (инициативы в бою).
- **Изменение**: Увеличивается тренировками рефлексов. Снижается травмами и болезнями нервной системы.

### Граничные случаи и Критические исходы
- **При `DEX` 0**: Персонаж полностью парализован (абсолютно обездвижен).

### Архитектура Rust
```rust
pub fn check_dex_state(dex_val: u8) -> Result<(), &'static str> {
    if dex_val == 0 {
        return Err("Character is utterly immobile.");
    }
    Ok(())
}
```

## Charisma (CHA) - Харизма
Определяет привлекательность персонажа, его манеру поведения и то, как он располагает к себе людей.

### Механика / Концепция
- **Связанный бросок**: `Charm roll` (`CHA × 5`).
- **Применение**: Формирует первое впечатление, физическое и эмоциональное притяжение. 
- **Изменение**: Может повышаться физическими тренировками, пластической хирургией, этикетом и даже впечатляющей экипировкой. Снижается из-за болезней и уродливых травм.

### Граничные случаи и Критические исходы
- **При `CHA` 0**: Персонаж становится либо абсолютно одиозным (вызывающим физическое отвращение у любого встречного), либо настолько невзрачным, что его присутствие перестает регистрироваться окружающими.

### Архитектура Rust
```rust
pub fn check_cha_state(cha_val: u8) -> Result<(), &'static str> {
    if cha_val == 0 {
        return Err("Character is entirely odious or completely nondescript.");
    }
    Ok(())
}
```

## Опциональное правило: Культурные модификаторы (Cultural Characteristic Modifiers)
Применение бонусов и штрафов к характеристикам в зависимости от культуры персонажа.

### Механика / Концепция
Некоторые культуры (или фантастические расы) могут иметь предрасположенность к определенным характеристикам (например, повышенный `SIZ`). Гейммастеру рекомендуется:
- Выдавать такие бонусы с осторожностью.
- Балансировать их: положительный бонус должен уравновешиваться негативным штрафом (или все культуры должны получать сопоставимые, но разные бонусы).
- **Важное правило:** Крайне не рекомендуется давать штраф к `INT` (Интеллекту) в качестве балансировки, независимо от контекста. Игрок не должен наказываться за выбор культуры.

### Архитектура Rust
```rust
pub struct CulturalModifier {
    pub stat_name: String,
    pub modifier: i8,
}

pub fn apply_cultural_modifiers(stats: &mut Characteristics, modifiers: &[CulturalModifier]) {
    for m in modifiers {
        if m.stat_name == "INT" && m.modifier < 0 {
            // Предупреждение логики движка, следуя указаниям рулбука
            println!("Warning: Penalizing INT is highly discouraged!");
        }
        // Логика применения модификатора с учетом границ 1..=255
    }
}
```
