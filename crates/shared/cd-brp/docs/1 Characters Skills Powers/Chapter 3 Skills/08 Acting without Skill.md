## Действие без навыка (Acting without Skill)
Механика разрешения ситуаций, в которых персонаж пытается совершить действие, требующее навыка, рейтинг которого у него равен `0%` (нет базового шанса и не вложены очки).

### Механика / Концепция
Если `Gamemaster` (Гейммастер) согласен, что выполнение задачи в принципе возможно для нетренированного человека, система предоставляет два варианта вычисления шанса на успех:

**1. Использование бонуса категории (Skill Category Bonus):**
Если в игре используется опциональное правило [[Skill Category Bonuses and Base Chances#Опциональное правило: Бонусы категорий навыков (Skill Category Bonuses)|Skill Category Bonuses]], то значение модификатора категории становится базовым шансом на успех. Это отражает ситуацию, когда сырой природный талант компенсирует недостаток тренировок.
- *Опыт:* Если действие успешно, и сам навык подразумевает возможность улучшения через практику, персонаж **получает** отметку опыта (`Experience Check`).

**2. Дикий шанс (Wild Chance):**
Если бонусы категорий не используются или равны нулю, персонаж может попытаться совершить действие "наобум".
- **Стандартный Wild Chance**: Шанс на успех строго фиксирован и равен `1%`.
- **"Отче наш" (Hail Mary)**: С разрешения Гейммастера, если в ситуации может сыграть роль слепая удача, шанс на успех равен `POW × 1` (значение характеристики `POW` в процентах).
- *Опыт:* При любом из вариантов `Wild Chance`, в случае успеха отметка опыта (`Experience Check`) **не выдается**, так как успех является результатом исключительно слепой удачи, а не применения таланта или навыка.

### Архитектура Rust
С точки зрения архитектуры, попытка использовать навык со значением `0` требует функции-резолвера, которая вернет целевое значение для броска `D100` и булевый флаг, разрешающий начисление опыта.

```rust
pub enum UntrainedActionType {
    /// Использование бонуса категории (значение бонуса передается внутри)
    CategoryBonus(u16),
    /// Базовый шанс 1%
    WildChance,
    /// Бросок на слепую удачу, равный POW * 1
    HailMary(u8),
}

pub struct UntrainedRollTarget {
    pub target_chance: u16,
    pub grants_experience: bool,
}

pub fn resolve_untrained_action(action_type: UntrainedActionType) -> UntrainedRollTarget {
    match action_type {
        UntrainedActionType::CategoryBonus(bonus) => UntrainedRollTarget {
            target_chance: bonus,
            grants_experience: true, // Природный талант позволяет учиться
        },
        UntrainedActionType::WildChance => UntrainedRollTarget {
            target_chance: 1,
            grants_experience: false, // Слепая удача не дает опыта
        },
        UntrainedActionType::HailMary(pow_val) => UntrainedRollTarget {
            target_chance: pow_val as u16,
            grants_experience: false, // Слепая удача не дает опыта
        }
    }
}
```

### Граничные случаи и Критические исходы
Если бонус категории (`Skill Category Bonus`) вычисляется как отрицательное значение (штраф), метод `CategoryBonus` становится неприменимым (шанс не может быть меньше 0). В этом случае игрок должен полагаться на `Wild Chance` (1%). Выпадение `01` на кубиках при `Wild Chance` является успехом, но по правилам системы не квалифицируется для получения `Experience Check`.
