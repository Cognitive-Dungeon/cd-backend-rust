## Категории Навыков (Skill Categories)
Системная классификация всех навыков в игре.

### Механика / Концепция
Навыки разделены на шесть категорий. Эта классификация используется как руководство для понимания области применения навыка, а также для работы опциональной механики Бонусов Категорий ([[Step Five - Derived Characteristics#Опциональное правило: Skill Bonuses (Бонусы к Категориям Навыков)|Skill Category Bonuses]]).

1. **Combat (Боевые)**: Мастерство владения оружием и боевые маневры.
2. **Communication (Социальные/Коммуникативные)**: Общение, чтение и межличностные взаимодействия.
3. **Manipulation (Манипуляции)**: Задачи, требующие точной зрительно-моторной координации (ремонт, ловкость рук).
4. **Mental (Ментальные)**: Специфические знания и индивидуальные суждения.
5. **Perception (Восприятие)**: Сбор и интерпретация информации из окружающей среды.
6. **Physical (Физические)**: Демонстрация силы, ловкости и атлетики.

### Архитектура Rust
```rust
#[derive(Debug, Clone, PartialEq, Eq)]
pub enum SkillCategory {
    Combat,
    Communication,
    Manipulation,
    Mental,
    Perception,
    Physical,
}
```
