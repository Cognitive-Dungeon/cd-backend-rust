## Роль навыков (Introduction)
Навыки лежат в основе разрешения большинства конфликтов и задач в игре.

### Концепция
В процессе игры персонаж принимает решения и сталкивается с множеством испытаний. Большинство значимых действий, которые персонаж может попытаться совершить, определяются и разрешаются через его навыки (`Skills`).

## Определение Навыков (Defining Skills)
Базовая механика того, как знания и таланты персонажа выражаются в цифрах.

### Механика / Концепция
Навык (`Skill`) представляет собой конкретный набор знаний и способностей. 
Каждый навык оценивается по процентной шкале от `0` до `100` (иногда значение может превышать 100%). Это значение называется рейтингом навыка (`Skill Rating`). Чем выше это число, тем лучше персонаж владеет данным навыком.

Базовый список навыков, представленный в системе, не является исчерпывающим. В зависимости от жанра и требований конкретной игры `Gamemaster` (Гейммастер) может:
- Создавать новые навыки.
- Переименовывать или переклассифицировать существующие.
- Удалять навыки, которые не подходят под сеттинг.
- Добавлять новые специализации.

### Архитектура Rust
Поскольку список навыков динамичен, в коде движка навыки должны определяться через конфигурацию данных, а не хардкодиться как перечисления (enums).

```rust
pub type SkillRating = u16; // Используем u16, так как рейтинг может быть > 100

pub struct SkillDefinition {
    pub id: String,
    pub name: String,
    pub category: String, // Combat, Mental, Physical и т.д.
    pub default_base_chance: SkillRating,
    pub requires_speciality: bool,
}

pub struct CharacterSkill {
    pub definition_id: String,
    pub rating: SkillRating,
}
```
