## Optional Rules
Система Basic Roleplaying (BRP) имеет модульную структуру. За годы развития в игру было добавлено множество подсистем, адаптирующих ядро под конкретные игровые жанры и ситуации.

### Концепция
Опциональные правила — это изолированные механики, которые `Gamemaster` (Гейммастер) может включать или отключать для настройки системы. В книге правил они визуально выделены в специальные текстовые блоки и снабжены комментариями о том, как они влияют на игру и взаимодействуют с другими модулями. В некоторых случаях опциональные правила могут полностью изменять базовые (ядерные) механики системы.

Примеры опциональных подсистем:
- Расширенная система боя (для фэнтези).
- Правила безумия (`Insanity`) и расследований (для хорроров).
- Правила для транспортных средств и космических кораблей.
- Системы великих страстей (`Passions`) и черт личности.
- Различные магические системы, подходящие под жанр.

**Важное требование:** Набор используемых опциональных правил необходимо определить **до начала игры**, так как они напрямую влияют на процесс создания персонажа. 

Подробные рекомендации о том, какие опциональные правила лучше всего подходят для конкретных миров, даны в [[Chapter 10: Settings]], а полный структурированный список всех существующих опциональных модулей представлен в [[Chapter 9: Gamemastering]].

### Архитектура Rust
Для программиста опциональные правила представляют собой набор конфигурационных флагов (Feature Flags), которые определяют логику работы движка для конкретной игровой сессии. Эта конфигурация должна создаваться на этапе инициализации игры (до генерации персонажей) и пробрасываться во все зависимые подсистемы.

```rust
// Структура конфигурации сессии, определяющая включенные модули
pub struct GameConfig {
    pub enable_advanced_combat: bool,
    pub enable_insanity_system: bool,
    pub enable_vehicles_and_spaceships: bool,
    pub enable_passions: bool,
    pub enable_personality_traits: bool,
    pub magic_system: MagicSystemType,
    // Другие флаги опциональных правил...
}

pub enum MagicSystemType {
    None,
    BasicMagic,
    Sorcery,
    Superpowers,
    PsychicAbilities,
    Mutations,
}

impl GameConfig {
    // Инициализация "чистого" ядра без опциональных надстроек
    pub fn default_core() -> Self {
        Self {
            enable_advanced_combat: false,
            enable_insanity_system: false,
            enable_vehicles_and_spaceships: false,
            enable_passions: false,
            enable_personality_traits: false,
            magic_system: MagicSystemType::None,
        }
    }
}
```
