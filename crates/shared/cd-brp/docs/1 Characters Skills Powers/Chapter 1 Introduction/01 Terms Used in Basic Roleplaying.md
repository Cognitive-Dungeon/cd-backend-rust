## Ability
Общий термин для всего, что персонаж может делать или чувствовать (навык, страсть и т.д.), оцениваемый по шкале от 1 до 100. При успешном броске способности персонаж обычно получает проверку опыта.

### Концепция
Базовое понятие для любой измеряемой в процентах величины.

### Архитектура Rust
```rust
pub type AbilityRating = u8;
```

## Characteristic
Физические, ментальные и духовные атрибуты персонажа (`Strength`, `Constitution`, `Size`, `Intelligence`, `Power`, `Dexterity`, `Charisma`).

### Концепция
Оцениваются по числовой шкале (обычно 3–18), где 10-11 является средним значением для человека.
> For example, if the initial maximum characteristic is 18, a STR 17 means your character is extremely strong, while a DEX 7 means they are a bit clumsy.

### Архитектура Rust
```rust
pub struct Characteristics {
    pub str: u8,
    pub con: u8,
    pub siz: u8,
    pub int: u8,
    pub pow: u8,
    pub dex: u8,
    pub cha: u8,
}
```

## Characteristic Roll
Бросок на основе `Characteristic`, переведенный в процентное значение путем умножения.

### Концепция
Значение характеристики умножается на число (обычно `x5`, но могут использоваться и другие множители) для получения шанса в процентах, после чего кидается `D100`.
```rust
// Псевдокод
chance = characteristic_value * multiplier;
```
> For example, if your character’s Intelligence characteristic is 14, they have a 42% chance at succeeding with a characteristic check with a multiple of ×3.

### Архитектура Rust
```rust
pub fn characteristic_roll_target(stat: u8, multiplier: u8) -> u8 {
    stat.saturating_mul(multiplier)
}
```

## Combat Round

### Концепция
Внутриигровое время, за которое происходят действия. Несколько секунд `Combat Round` могут занимать несколько минут реального времени за столом.

### Архитектура Rust
```rust

```

## Critical Success
Результат проверки навыка, равный 1/20 (или 5%) от обычного шанса на успех. 

### Концепция
Обычно награждается более значительными результатами, а иногда требуется для достижения успеха в принципе. Округляется в большую сторону.
```rust
// Псевдокод
critical_target = ceil(target_chance / 20.0);
```
> For example, if the regular chance for success is 75%, any roll of 4 or under is a critical success (1/20 of 75% is 3.75, rounded up to 4).

### Архитектура Rust
```rust
pub fn get_critical_target(chance: u8) -> u8 {
    (chance as f32 / 20.0).ceil() as u8
}
```
### Граничные случаи и Критические исходы
Если значение получается дробным, применяется математическое округление вверх (`ceil`).

> For example, a roll of 60 (or 6) and 2 equals a result of 62.

## Difficulty Modifier
Сумма, на которую корректируется шанс навыка в зависимости от обстоятельств применения.

### Концепция
- `Automatic` (Автоматически): бросок не требуется.
- `Easy` (Легко): навык удваивается (`x2`).
- `Average` (Средне): без модификаций.
- `Difficult` (Сложно): навык уменьшается вдвое (`x0.5`).
- `Impossible` (Невозможно): бросок не делается, или шанс `01%` (на усмотрение ГМ'а).

### Архитектура Rust
```rust
pub enum DifficultyModifier {
    Automatic,
    Easy,
    Average,
    Difficult,
    Impossible,
}

pub fn apply_difficulty(base: u8, diff: DifficultyModifier) -> Option<u8> {
    match diff {
        DifficultyModifier::Automatic => None,
        DifficultyModifier::Easy => Some(base.saturating_mul(2)),
        DifficultyModifier::Average => Some(base),
        DifficultyModifier::Difficult => Some(base / 2),
        DifficultyModifier::Impossible => Some(1), // 01%
    }
}
```

## Roll
Бросок `D100` для определения успешности применения навыка, способности или силы.

### Концепция
Результатом может быть: `Critical Success`, `Special Success`, `Success`, `Failure` или `Fumble`.

### Архитектура Rust
```rust
pub enum RollResult {
    CriticalSuccess,
    SpecialSuccess,
    Success,
    Failure,
    Fumble,
}
```

## Sanity
Опциональная система, в которой ментальное здоровье персонажа измеряется его способностью переносить ужасные сцены и события.

### Концепция
При сильном падении `Sanity` персонаж может сойти с ума (временно или навсегда). Детальная механика раскрывается в следующих разделах.

### Архитектура Rust
```rust
pub struct Sanity {
    pub current: i16,
    pub max: u16,
}
```

## Skill
Способность, обучение, сфера знаний, талант или специальность. 

### Концепция
Оцифровывается как уровень навыка (`Skill Rating`) и используется в проверках (`Skill Rolls`), где против этого рейтинга кидаются процентные кубики.

### Архитектура Rust
```rust
pub struct Skill {
    pub name: String,
    pub rating: u16,
}
```

## Skill Rating
Степень компетентности персонажа в навыке.

### Концепция
Выражается числом от `00%` (полное отсутствие навыка) до `100%` и выше (эксперт мирового класса).

### Архитектура Rust
```rust
pub type SkillRating = u16;
```

## Special Success
Бросок, равный `1/5` от требуемого числа для успеха. Означает, что персонаж выполнил задачу исключительно хорошо, превзойдя обычный `Success`.

### Концепция
Особенно важно в бою. Округляется. Детальная механика округления и дополнительных эффектов раскрывается в следующих разделах.
```rust
// Псевдокод
special_target = target_chance / 5.0;
```
> For example, a character with 70% in a skill who rolls 14 or lower has achieved a special success.

### Архитектура Rust
```rust
pub fn get_special_target(chance: u8) -> u8 {
    (chance as f32 / 5.0).ceil() as u8 // Если используется round up как в critical
}
```
### Граничные случаи и Критические исходы
Требует вычисления дроби с последующим округлением для определения порогового значения на `D100`.

## Success
Результат процентного броска, при котором персонаж выполнил задачу адекватно и достиг среднего качества успеха.

### Концепция
Если бросок равен или ниже рейтинга способности, он является успешным. Если бросок очень низкий — это может быть `Special Success` или `Critical Success`.
> For example, if your character has a 70% in a skill, and rolls 70 or lower, they have succeeded.

### Архитектура Rust
```rust
pub fn is_success(roll: u8, rating: u8) -> bool {
    roll <= rating
}
```
