# cd-ecs

ECS-компоненты, реестр сущностей и пространственный индекс.  
Определяет "словарь" игровых объектов — из чего они состоят.

## Публичный API

### Компоненты

- `Position` — мировая позиция (`WorldPos`)
- `Render` — визуальное представление (`Glyph`)
- `Stats` — базовые характеристики (HP, MP и их максимумы)
- `Name` — человекочитаемое имя
- `Guid` — обёртка над `ObjectGuid` для ECS
- `Controller` — указывает кто управляет сущностью (агент)

### Инфраструктура

- `EntityRegistry` — двусторонний маппинг `ObjectGuid ↔ bevy Entity`
- `SpatialGrid` — пространственный индекс: быстрый поиск сущностей по позиции

## Не входит в scope

- ECS-ресурсы (обёртки `Resource`) — это `cd-engine/world/resources.rs`
- Игровая логика и системы — это `cd-engine/systems/`

## Зависит от

- `cd-core`
- `cd-common`
- `bevy_ecs`
