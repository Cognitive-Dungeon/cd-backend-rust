# cd-map

## Назначение

Иерархическая карта мира: World → Shard → Region → Chunk → Tile.

## Публичный API

- `World` — точка входа, хранит шарды
- `Chunk` — 32×32 тайлов, основная единица симуляции
- `TileFlags` (bitmask.rs) — битовые флаги тайла

## Что НЕ делает этот крейт

- Не знает про игроков, существ, предметы
- Не знает про сеть

## Зависит от

- cd-core (TilePos, WorldPos)
