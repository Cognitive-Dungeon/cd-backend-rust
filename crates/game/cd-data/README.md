# cd-data

Загрузка и хранение игровых данных из внешних источников (Depot/JSON).  
Это слой данных — он читает, парсит и отдаёт определения. Не симулирует.

## Публичный API

### Depot

- `Depot` — загруженная база данных игры (листы с определениями)
- `FromDepotLine` — трейт: реализуй чтобы десериализовать свой тип из строки Depot

### Определения (`defs/`)

- `MaterialDef` — определение материала тайла (slug, имя, флаги, глиф)
- `CreatureDef` — определение существа (id, имя, HP, MP, скорость, глиф)
- `FurnitureDef` — определение мебели (id, имя, solid/opaque, глиф)

## Не входит в scope

- ECS-компоненты и ресурсы (это `cd-ecs` и `cd-engine`)
- Симуляция и игровая логика
- Сетевые типы

## Зависит от

- `cd-core`
- `cd-common`
